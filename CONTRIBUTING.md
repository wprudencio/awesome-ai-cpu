# Contributing to Awesome AI CPU

Thanks for helping curate this list! These guidelines keep the list high-quality and easy to maintain.

## What belongs here

- **Open source** projects (rare exceptions like LM Studio must be clearly marked).
- Projects that run **fully on CPU** — no GPU required. Hybrid projects are fine only if CPU-only execution genuinely works.
- Projects that actually work: check that the link resolves, the repo is not archived, and the README backs up any performance claims.

## Adding a project

1. Match the existing entry format:

   ```markdown
   - [**Name**](https://github.com/owner/repo) — One sentence: what it does and why it is CPU-friendly.
   ```

2. Put it in the right section. Ask yourself: is it a chat UI, an inference engine, a model, a framework, or a tool?
3. Search the README for the name **and** the URL first — no duplicates, even across sections.
4. Do not include star counts, badges, or marketing language — they go stale.
5. Added a new section? Update the Table of Contents to match.

## Before you submit

- [ ] Link resolves (not 404, not archived — or flagged with a note like Piper's)
- [ ] Project runs on CPU-only hardware
- [ ] Description is one sentence, factual, ends with a period
- [ ] No duplicate entry elsewhere in the list

Small fixes (typos, broken links, outdated blurbs) are always welcome — no checklist needed.
